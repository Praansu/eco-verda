# EcoVerda

marketplace-ish site for eco friendly products. made it to learn next.js properly.

## stack

next.js, tailwind, mongodb

## run it

```bash
npm install
npm run dev
```

needs a `MONGODB_URI` in `.env.local`, otherwise products page breaks (learned that the hard way).
